# E-Signature — mandatory agent onboarding

**Before every task** read [the full Agent Model & Parallel Execution Policy](docs/agents/AGENT_MODEL_AND_PARALLEL_EXECUTION_POLICY.md) and existing repository instructions. Confirm and acknowledge exact model and Medium Thinking. **Sonnet 5.5 Medium alone writes/refactors/fixes code**. **Haiku 5.5 Medium** runs tests, Playwright and reports, and installs/configures approved *nonproduction local* development/test tools and isolated test databases subject to existing authorization. **Opus 5.5 Medium** only does exceptional Owner-approved analysis after a documented failed Sonnet attempt. **At most 4 active direct+indirect subagents** per principal. Never bypass security, database, resources, Git/merge or Owner-only acceptance gates. Pass policy to subagents; provide evidence and clickable Markdown links.
